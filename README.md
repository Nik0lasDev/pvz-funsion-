## 🎮 Como jogar

1. Abra o jogo pelo link **JOGAR AGORA** no topo.
2. Escolha uma carta de planta.
3. Toque ou clique em um quadrado vazio do gramado para plantar.
4. Toque nos sóis ☀️ que aparecerem para coletá-los.
5. Combine plantas para sobreviver aos zumbis e proteger a casa.
6. Se um zumbi alcançar a casa, a partida termina. Pressione **Reiniciar** para jogar de novo.

## 🚀 Executar localmente

**Opção rápida:** baixe ou clone o repositório e abra `index.html` em um navegador moderno.

```bash
git clone https://github.com/Nik0lasDev/pvz-funsion-.git
cd pvz-funsion-
```

Depois, abra o arquivo `index.html`.
