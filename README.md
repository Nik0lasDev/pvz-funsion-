# Jardim contra Zumbis 🌻

Protótipo jogável de defesa de jardim inspirado no gênero Plants vs. Zombies, feito em HTML, CSS e JavaScript puro. Não precisa instalar dependências.

## Como jogar

1. Abra `index.html` no navegador ou publique o repositório com GitHub Pages.
2. Selecione uma planta e toque/clique em um quadrado vazio do gramado.
3. Colete os sóis para conseguir plantar mais unidades.
4. Use atiradoras para atacar, girassóis para gerar sóis e batatas-defesa para atrasar zumbis.
5. Se um zumbi chegar à casa, a partida termina. Use **Reiniciar** para tentar novamente.

## Controles

Compatível com mouse, toque e telas pequenas. Todo o jogo roda no navegador, sem bibliotecas externas.
